# 🐱 Gerador de Fatos sobre Gatos

Este projeto consome a API [CatFact](https://catfact.ninja/), traduz as curiosidades para Português e permite salvar as favoritas.

##  Como rodar
1. Crie o ambiente virtual: `python -m venv venv`
2. Ative o venv: `source venv/bin/activate` (ou `.\venv\Scripts\activate` no Windows)
3. Instale as dependências: `pip install -r requirements.txt`
4. Rode: `python main.py`

## Tecnologias
- Python 3
- Requests (API)
- Deep Translator (Tradução)
